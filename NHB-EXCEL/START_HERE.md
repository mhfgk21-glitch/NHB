# 🚀 دليل البناء السريع

## للمطورين: كيفية بناء التطبيق

### الخطوة 1️⃣: التأكد من المتطلبات
تأكد من تثبيت Python والمكتبات المطلوبة:
```bash
pip install -r requirements.txt
pip install pyinstaller
```

### الخطوة 2️⃣: بناء التطبيق
انقر نقراً مزدوجاً على:
```
build.bat
```

أو من سطر الأوامر:
```bash
build.bat
```

### الخطوة 3️⃣: النتائج
بعد اكتمال البناء ستجد:

**مجلد `dist`:**
- `نسمة هوى بغداد.exe` - الملف التنفيذي
- `PM.xlsx` - القالب
- `template_config.json` - الإعدادات
- `README.md` - التعليمات
- `icon.ico` - الأيقونة

**مجلد `Portable`:**
- نفس محتويات `dist` لكن جاهز للنقل مباشرة

### الخطوة 4️⃣ (اختياري): إنشاء ملف ZIP
لإنشاء حزمة مضغوطة للتوزيع:
```bash
create_portable_zip.bat
```

سينتج ملف: `نسمة_هوى_بغداد_محمول.zip`

## للمستخدمين: كيفية الاستخدام

### إذا حصلت على ملف ZIP:
1. فك الضغط عن الملف
2. افتح المجلد الناتج
3. شغّل `نسمة هوى بغداد.exe`

### إذا حصلت على مجلد Portable:
1. افتح المجلد
2. شغّل `نسمة هوى بغداد.exe`

**لا تحتاج تثبيت أي شيء!**

## الملفات الموجودة في المشروع

### ملفات البناء:
- `build.bat` - سكريبت البناء الرئيسي
- `create_portable_zip.bat` - إنشاء ملف ZIP

### ملفات التوثيق:
- `README.md` - نظرة عامة ودليل سريع
- `BUILD_INSTRUCTIONS.md` - تعليمات البناء التفصيلية
- `دليل_الاستخدام.md` - دليل شامل للمستخدمين

### ملفات البرنامج:
- `N-H-B EXCEL.py` - الكود المصدري
- `PM.xlsx` - القالب الناتج
- `template_config.json` - إعدادات الشركات
- `icon.ico` / `icon.png` - أيقونة التطبيق
- `requirements.txt` - المكتبات المطلوبة

## نصائح مهمة

### ✅ قبل البناء:
- تأكد من إغلاق أي ملفات Excel مفتوحة
- تأكد من وجود مساحة كافية (~200 MB)
- تأكد من تثبيت PyInstaller

### ✅ بعد البناء:
- اختبر الملف التنفيذي قبل التوزيع
- احتفظ بنسخة من `template_config.json`
- يمكنك حذف مجلد `build` بعد البناء

### ✅ للتوزيع:
- استخدم مجلد `Portable` أو ملف ZIP
- تأكد من وجود جميع الملفات المطلوبة
- أرفق `دليل_الاستخدام.md` للمستخدمين

## استكشاف الأخطاء

### خطأ: "pyinstaller not found"
```bash
pip install pyinstaller
```

### خطأ: "module not found"
```bash
pip install -r requirements.txt
```

### خطأ: "file in use"
- أغلق جميع ملفات Excel
- أغلق البرنامج إذا كان قيد التشغيل
- أعد تشغيل `build.bat`
