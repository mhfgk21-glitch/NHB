# 🧾 نسمة هوى بغداد - نظام تعبئة القوالب

## 🚀 البدء السريع (للنسخة المحمولة)

### إذا كنت تستخدم الملف التنفيذي (.exe):
1. **افتح مجلد** `Portable` أو `dist`
2. **شغّل** `نسمة هوى بغداد.exe`
3. **لا تحتاج** تثبيت Python أو أي برامج إضافية!

---

## 📋 الملفات المطلوبة للتشغيل:

### النسخة التنفيذية (موصى بها):
- ✅ **نسمة هوى بغداد.exe** - البرنامج التنفيذي
- ✅ **PM.xlsx** - القالب الناتج
- ✅ **template_config.json** - إعدادات الشركات (13 شركة)

### النسخة البرمجية (للمطورين):
- **N-H-B EXCEL.py** - البرنامج الرئيسي
- **PM.xlsx** - القالب الناتج
- **template_config.json** - إعدادات الشركات

#### المكتبات المطلوبة:
```bash
pip install openpyxl customtkinter tkinterdnd2
```

---

## 📦 النقل إلى حاسوب آخر:

### ✅ الطريقة الأسهل (النسخة المحمولة):
1. **انسخ مجلد** `Portable` بالكامل
2. **الصقه** في أي مكان على الجهاز الجديد
3. **شغّل** `نسمة هوى بغداد.exe`
4. **جاهز للاستخدام!** 🎉

### الطريقة البرمجية:
1. انسخ المجلد بالكامل إلى الحاسوب الجديد
2. ثبّت Python (إذا لم يكن مثبتاً)
3. ثبّت المكتبات المطلوبة
4. شغّل: `python "N-H-B EXCEL.py"`
